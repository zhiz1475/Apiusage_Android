# ApiUsageBar Android

Capacitor Android client for Kapibala API usage. JDK 21, Android API 36.

## Build

```bash
npm install
npm run cap:sync
npm run android:debug
```

Debug APK: [Releases](https://github.com/zhiz1475/Apiusage_Android/releases)

测试账号、Token 与本地缓存均不会提交到仓库。项目仅包含 Android 客户端源码与测试。

## Structure

- `src/mobile` mobile UI and data layer
- `android` Capacitor Android wrapper
- `tests/mobile` UI and data verification
- `docs` architecture and release notes
